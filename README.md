# E-Commerce Web Automation Framework

Automation framework for an e-commerce workflow using Java, Selenium WebDriver, TestNG, Maven and Page Object Model.

## Tech Stack
- Java 21
- Selenium WebDriver
- TestNG
- Maven
- Page Object Model (POM)
- WebDriverManager
- Git/GitHub

## Application
SauceDemo: https://www.saucedemo.com/

## Test Flow
Login -> Product Selection -> Cart -> Checkout -> Order Confirmation

## Run
```bash
mvn clean test
```
